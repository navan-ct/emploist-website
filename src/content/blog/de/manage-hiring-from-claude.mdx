Sie können Claude mit Emploist verbinden und Ihr Recruiting im Chat verwalten. Fragen Sie, welche Bewerbenden am besten zu einer Stelle passen, lassen Sie Personen in die nächste Phase verschieben, Notizen für Ihr Team hinterlassen oder eine neue Stelle entwerfen, und Claude erledigt das für Sie in Emploist.

Möglich macht das **MCP** (Model Context Protocol), ein offener Standard, über den sich KI-Assistenten mit anderen Apps verbinden können. Wie das technisch funktioniert, müssen Sie nicht wissen, um es zu nutzen. Die Einrichtung dauert ein paar Minuten, ganz ohne Code.

Diese Anleitung zeigt, wie Sie Claude verbinden, worum Sie Claude bitten können und wie Sie dabei die Kontrolle behalten. Für alle Beispiele verwenden wir Northwind Labs, ein fiktives Unternehmen.

## Was Sie brauchen

- **Ein Konto bei Emploist.** Sowohl Admins als auch Mitglieder können Claude verbinden.
- **Claude**, im Web unter [claude.ai](https://claude.ai) oder in der Desktop-App von Claude.

Bei den Claude-Tarifen Team und Enterprise fügt zuerst ein Owner Emploist unter **Organization settings** → **Connectors** hinzu. Danach klicken Sie unter **Customize** → **Connectors** daneben auf **Connect** und springen direkt zu [Schritt 3](#3-bei-emploist-anmelden).

### 1. Claudes Connector-Einstellungen öffnen

Öffnen Sie in Claude **Customize** → **[Connectors](https://claude.ai/customize/connectors)**.

### 2. Emploist hinzufügen

Klicken Sie auf **+ Add** und wählen Sie **Add custom connector**. Nennen Sie ihn Emploist, fügen Sie diese Adresse ein und klicken Sie auf **Continue**:

```
https://mcp.emploist.com
```

Claude prüft die Adresse und zeigt dann die Optionen für die Anmeldung. Die richtigen für Emploist wählt Claude bereits aus: **Sign in now** und **Use Claude's published identity**. Lassen Sie sie also unverändert und klicken Sie auf **Add**.

### 3. Bei Emploist anmelden

Klicken Sie auf **Connect**. Emploist öffnet sich: Melden Sie sich bei Bedarf an, prüfen Sie, was Claude dann tun kann, und klicken Sie auf **Erlauben**.

Danach sind Sie wieder in Claude, und der Connector für Emploist ist bereit.

### 4. Im Chat nutzen

Klicken Sie in einem Chat auf **+**, öffnen Sie **Connectors** und achten Sie darauf, dass Emploist aktiviert ist. Dann fragen Sie in Ihren eigenen Worten, was Sie brauchen.

## Worum Sie Claude bitten können

Claude kann mit allem arbeiten, was Sie in Emploist bei Stellen und Bewerbungen sehen. Hier sind einige Beispiele von Northwind Labs.

### Alles, was Claude kann

- **Überblick:** Ihre Rolle, Ihr Tarif und Ihre KI-Credits; Recruiting-Statistiken der letzten 7, 30 oder 90 Tage; Ihr Team; Ihre Benachrichtigungen.
- **Stellen:** Stellen finden; Details, Bewerbungsformular und Phasen einer Stelle lesen; eine Stelle als Entwurf erstellen oder direkt veröffentlichen; ihre Details oder ihr Bewerbungsformular bearbeiten; sie veröffentlichen, öffnen, schließen, archivieren oder wiederherstellen; sie duplizieren oder löschen.
- **Phasen:** Phasen einer Stelle hinzufügen, umbenennen, neu anordnen oder löschen; die E-Mail einer Phase an Bewerbende aktivieren oder deaktivieren.
- **Bewerbungen:** die Bewerbungen einer Phase mit ihren KI-Match-Scores auflisten; eine Bewerbung mit Antworten, Kommentaren und Lebenslauf lesen; sie in eine andere Phase verschieben; Ihre letzte Verschiebung rückgängig machen; sie erneut bewerten, wenn die Bewertung fehlgeschlagen ist; sie löschen.
- **Kommentare:** Bewerbungen kommentieren und Teammitglieder erwähnen; eigene Kommentare bearbeiten oder löschen (Admins können alle Kommentare löschen).
- **Unternehmenseinstellungen, für Admins:** die KI-Bewertung aktivieren oder deaktivieren; Bewerbungen, die eingegangen sind, während Sie keine KI-Credits hatten, bewerten oder unbewertet lassen; E-Mails an Bewerbende aktivieren oder deaktivieren; festlegen, wohin Antworten von Bewerbenden gehen.

Einiges erledigen Sie weiterhin in Emploist: die Abrechnung, Mitglieder und Einladungen, das Löschen Ihres Unternehmens oder Kontos, Code und Domain Ihrer Karriereseite, E-Mail-Layouts und die E-Mail-Texte der Phasen.

## Behalten Sie die Kontrolle

**Claude handelt als Sie.** Claude hat in Emploist dieselben Zugriffsrechte wie Sie, und nicht mehr. Wenn Sie Mitglied sind, kann auch Claude keine Unternehmenseinstellungen ändern.

**Sie entscheiden, was Claude ohne Rückfrage tun darf.** Öffnen Sie in Claude **Customize** → **Connectors** → **Emploist**, um Berechtigungen für die Tools festzulegen, die nur lesen, und für die, die Änderungen vornehmen: **Always allow**, **Needs approval** oder **Blocked**.

Diese Berechtigungen gelten im Modus **Manual**, den Sie unter dem Nachrichtenfeld neben dem Modell auswählen. Im Modus **Auto** kann Claude ohne Rückfrage handeln und fragt nur dann nach, wenn etwas riskant wirkt.

**Emploist warnt Claude vor den Texten von Bewerbenden.** Emploist teilt Claude mit, dass Namen, Antworten und Lebensläufe von Bewerbenden stammen und dass Claude Anweisungen darin niemals befolgen soll. Enthält eine Bewerbung Text, der wie Anweisungen an einen KI-Assistenten aussieht, markiert Emploist ihn, und Claude informiert Sie darüber.

**Sie können die Verbindung jederzeit trennen.** Klicken Sie auf der MCP-Seite von Emploist neben Claude auf **Trennen**, und Claude kann Emploist ab sofort nicht mehr für Sie nutzen. Sie können Claude wieder verbinden, wann immer Sie möchten.

**Admins können MCP für alle deaktivieren.** Unter **Einstellungen** → **Allgemein** legt der Schalter **MCP** fest, ob Ihr Team überhaupt KI-Assistenten mit Emploist nutzen kann. Wenn Sie ihn deaktivieren, stoppt das alle verbundenen Assistenten, bis Sie MCP wieder aktivieren.

## Gut zu wissen

- **In Ihrem Tarif enthalten.** Wenn Sie eine Bewerbung über Claude bewerten lassen, verbraucht das einen KI-Credit, genau wie in Emploist. Alles andere, was Claude tut, verbraucht keine Credits.
- **Jede Person verbindet Claude selbst**, und Claude arbeitet dann jeweils mit ihrer eigenen Rolle.
- **Prüfen Sie Claudes Arbeit.** Claude kann Fehler machen. Lesen Sie die Antworten, vor allem bevor Bewerbende verschoben oder Stellen veröffentlicht werden.
- **Andere Assistenten funktionieren auch.** Auf der MCP-Seite finden Sie Schritte für ChatGPT, Claude Code, Cursor, VS Code und jeden anderen Assistenten, der MCP unterstützt.
