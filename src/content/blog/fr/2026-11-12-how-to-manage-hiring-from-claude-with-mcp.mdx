Vous pouvez connecter Claude à Emploist et gérer vos recrutements en discutant. Demandez-lui quels candidats correspondent le mieux à une offre, ou chargez-le de faire passer des candidats à l’étape suivante, de laisser des notes à votre équipe ou de rédiger une nouvelle offre : il s’en occupe pour vous dans Emploist.

Tout cela fonctionne grâce au **MCP** (Model Context Protocol), un standard ouvert qui permet aux assistants IA de se connecter à d’autres applications. Nul besoin de savoir comment il fonctionne pour l’utiliser. La configuration prend quelques minutes et ne demande aucune ligne de code.

Ce guide explique comment connecter Claude, ce que vous pouvez lui demander et comment vous gardez le contrôle. Tous les exemples portent sur Fieldnote Labs, une entreprise fictive.

## Ce qu’il vous faut

- **Un compte Emploist.** Les administrateurs comme les membres peuvent connecter Claude.
- **Claude**, sur le web à l’adresse [claude.ai](https://claude.ai) ou dans l’application de bureau Claude.

Avec les forfaits Team et Enterprise de Claude, un propriétaire ajoute d’abord Emploist dans **Organization settings** → **Connectors**. Vous cliquez ensuite sur **Connect** à côté de lui dans **Customize** → **Connectors**, et passez directement à l’[étape 3](#3-se-connecter-à-emploist).

### 1. Ouvrir les paramètres des connecteurs de Claude

Dans Claude, ouvrez **Customize** → **[Connectors](https://claude.ai/customize/connectors)**.

### 2. Ajouter Emploist

Cliquez sur **+ Add** et choisissez **Add custom connector**. Nommez-le Emploist, collez cette adresse et cliquez sur **Continue** :

```
https://mcp.emploist.com
```

Cliquez sur **Connect**. Emploist s’ouvre : connectez-vous si on vous le demande, vérifiez ce que Claude pourra faire, puis cliquez sur **Autoriser**.

### 4. L’utiliser dans une discussion

Dans une discussion, cliquez sur **+**, ouvrez **Connectors** et vérifiez qu’Emploist est activé. Demandez ensuite ce dont vous avez besoin, avec vos propres mots.

### Tout ce que Claude peut faire

- **Vue d’ensemble :** votre rôle, votre forfait et vos crédits IA ; les statistiques de recrutement des 7, 30 ou 90 derniers jours ; votre équipe ; vos notifications.
- **Offres :** rechercher des offres ; consulter les informations, le formulaire de candidature et les étapes d’une offre ; créer une offre en brouillon ou la publier ; modifier ses informations ou son formulaire de candidature ; la publier, l’ouvrir, la clôturer, l’archiver ou la restaurer ; la dupliquer ou la supprimer.
- **Étapes :** ajouter, renommer, réorganiser ou supprimer les étapes d’une offre ; activer ou désactiver l’e-mail qu’une étape envoie aux candidats.
- **Candidatures :** lister les candidatures d’une étape avec les scores de compatibilité attribués par l’IA ; lire une candidature avec ses réponses, ses commentaires et son CV ; la déplacer vers une autre étape ; annuler votre dernier déplacement ; la réévaluer si l’évaluation a échoué ; la supprimer.
- **Commentaires :** commenter une candidature et mentionner des collègues ; modifier ou supprimer vos propres commentaires (les administrateurs peuvent supprimer ceux de tout le monde).
- **Paramètres de l’entreprise, pour les administrateurs :** activer ou désactiver l’évaluation par IA ; évaluer les candidatures arrivées alors que vous n’aviez plus de crédits IA, ou les laisser sans évaluation ; activer ou désactiver les e-mails aux candidats ; choisir où arrivent les réponses des candidats.

Certaines choses se gèrent uniquement dans Emploist : la facturation, les membres et les invitations, la suppression de votre entreprise ou de votre compte, le code et le domaine de votre page carrière, les mises en page des e-mails et le texte des e-mails d’étape.

## Garder le contrôle

**Claude agit en votre nom.** Il dispose des mêmes accès que vous dans Emploist, et rien de plus. Si vous êtes membre, Claude ne peut pas non plus modifier les paramètres de l’entreprise.

**Vous choisissez ce que Claude peut faire sans vous demander votre accord.** Dans Claude, ouvrez **Customize** → **Connectors** → **Emploist** pour définir les autorisations de ses outils en lecture seule et de ceux qui apportent des modifications : **Always allow**, **Needs approval** ou **Blocked**.

**Emploist met Claude en garde contre le texte des candidats.** Il indique à Claude que les noms, les réponses et les CV sont rédigés par les candidats, et qu’il ne faut jamais suivre les instructions qu’ils contiennent. Si une candidature contient du texte qui ressemble à des instructions destinées à un assistant IA, Emploist le signale, et Claude vous en informe.

**Vous pouvez déconnecter Claude à tout moment.** Sur la page Assistants IA d’Emploist, cliquez sur **Déconnecter** à côté de Claude : il cesse immédiatement de fonctionner pour vous. Vous pouvez le reconnecter quand vous le souhaitez.

**Les administrateurs peuvent désactiver le MCP pour tout le monde.** Dans **Paramètres** → **Général**, le bouton **MCP** détermine si votre équipe peut utiliser ou non des assistants IA avec Emploist. Le désactiver arrête tous les assistants connectés jusqu’à ce que vous le réactiviez.

## Bon à savoir

- **C’est inclus dans votre forfait.** Évaluer une candidature depuis Claude utilise un crédit IA, comme dans Emploist. Aucune autre action de Claude n’utilise de crédits.
- **Chacun connecte son propre Claude**, qui fonctionne avec son propre rôle.
- **Vérifiez le travail de Claude.** Claude peut faire des erreurs. Lisez ses réponses, surtout avant de déplacer des candidats ou de publier une offre.
- **D’autres assistants fonctionnent aussi.** La page Assistants IA propose des étapes pour ChatGPT, Claude Code, Cursor, VS Code et tout autre assistant compatible MCP.
